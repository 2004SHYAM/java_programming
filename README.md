Java Programming ☕
This repository contains a collection of Java programs that I have written to practice and demonstrate my programming skills. The programs cover a wide range of topics, from basic algorithms and data structures to more advanced concepts like object-oriented programming and database connectivity.

Contents 📜
The repository includes programs for:

Number Theory 🔢
Amstrong Number: Checks if a number is an Armstrong number.

Automorphic Number: Checks if a number is an Automorphic number.

Harshad Number: Checks if a number is a Harshad number.

Neon Number: Checks if a number is a Neon number.

Palindrome Number: Checks if a number is a Palindrome.

Perfect Number: Checks if a number is a Perfect number.

Perfect Square: Checks if a number is a perfect square.

Spy Number: Checks if a number is a Spy number.

Strong Number: Checks if a number is a Strong number.

Sunny Number: Checks if a number is a Sunny number.

Tech Number: Checks if a number is a Tech number.

Xylem and Phloem Number: Checks if a number is a Xylem or Phloem number.

Algorithms and Data Structures ⚙️
Bubble Sort: Implements the Bubble Sort algorithm.

Factorial: Calculates the factorial of a number.

Reverse a String: Reverses a given string.

Reverse a Number: Reverses a given number.

Object-Oriented Programming (OOP) 🧑‍💻
Bank System: A simple banking system application.

Employee Details: A program to manage employee details.

Student Details: A program to manage student details.

Database Connectivity 🗄️
JDBC: A simple example of Java Database Connectivity (JDBC).

Other Programs miscellaneous ✨
Aadhar Card Number Validation: Validates an Aadhar card number.

Login Page: A simple login page.

How to Use 🚀
To use these programs, you will need to have the Java Development Kit (JDK) installed on your computer. You can then compile and run the programs from the command line.

For example, to compile and run the Amstrongnumber.java program, you would use the following commands:

Bash

javac Amstrongnumber.java
java Amstrongnumber
